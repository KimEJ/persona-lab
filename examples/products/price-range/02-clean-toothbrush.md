# 소마 클린 S2 전동 칫솔

## 해결할 문제

칫솔을 움직이는 속도와 양치 시간을 매번 직접 조절해야 하는 부담을 줄인다. 한 사람이 집에서 매일 사용하는 충전식 칫솔이다.

## 주요 기능

- 음파 진동 방식. 일반 모드에서 분당 31,000회 진동한다.
- 일반 모드와 약한 모드 2개를 제공한다.
- 2분 뒤 자동으로 멈춘다. 30초마다 짧게 진동을 바꿔 구역 이동을 알린다.
- 칫솔을 강하게 누르면 진동을 낮추고 표시등을 켠다.
- 완충 후 최대 14일 사용. 하루 2회, 회당 2분 기준이다.
- USB-C 충전. 완충까지 약 3시간이 걸린다.
- 구성: 본체 1개, 부드러운 칫솔모 1개, 충전 케이블 1개, 칫솔모 덮개 1개.

## 현재 대안과의 차이

수동 칫솔과 달리 모터가 칫솔모를 진동시킨다. 휴대전화 앱 연결 없이 본체 버튼으로 조작한다. 양치 기록을 저장하거나 치아 상태를 진단하지 않는다.

## 효익의 근거

타이머가 양치 시간을 관리한다. 30초 간격 알림은 입안을 네 구역으로 나눠 닦을 때 사용할 수 있다. 압력 감지는 칫솔을 세게 누르는 동작을 알려준다.

## 사용 방법

칫솔모를 끼우고 치약을 묻힌다. 입안에 넣은 뒤 버튼을 눌러 모드를 선택한다. 칫솔모를 치아와 잇몸 경계에 가볍게 댄다. 사용 후 칫솔모를 헹구고 본체의 물기를 닦는다.

## 도입 조건·제약

새 본체 한 대의 기본 구성을 제공한다. USB 전원 어댑터는 별도로 준비한다. 칫솔모는 한 사람이 사용하며, 모가 벌어지면 교체한다. 본체를 물에 담그거나 충전 중에 사용하지 않는다. 치과 치료를 대체하지 않는다.

## 자료·권한 조건

계정, 앱, 인터넷 연결이 필요하지 않다. 양치 기록과 건강 정보를 수집하거나 전송하지 않는다.
