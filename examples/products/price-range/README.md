# 상품별 가격대 평가

줄 노트·전동 칫솔·로봇 청소기·전기자전거·전기 세단의 상품 문서입니다.

앱에서 **설정 가져오기**를 누르고 평가할 상품의 JSON 파일을 선택합니다. 각 파일은 상품 하나의 문서와 실행 조건을 불러와 별도 실험을 만듭니다.

| 설정 | 값 |
| --- | --- |
| 판매가격 | 미입력 |
| 최대 지불 가격대 설정 | 자동 |
| 통화·결제 주기 | JPY·일시불 |
| 표본 | 조건 제한 없이 100명 무작위 추출 |
| 반복 | 1회 |

기본 평가 7문항 → 사용 의향 → 최대 지불 가격대의 세 단계로 평가합니다. 판매가격을 입력하면 코드가 가격 수용 여부를 계산합니다.
대상 인원은 실행 전에 줄일 수 있습니다.

| 상품 | 설정 JSON | 문서 |
| --- | --- | --- |
| 라인노트 A5 96 | [줄 노트](01-line-note.json) | [Markdown](01-line-note.md) |
| 소마 클린 S2 | [전동 칫솔](02-clean-toothbrush.json) | [Markdown](02-clean-toothbrush.md) |
| 리브오 R3 | [로봇 청소기](03-floor-robot.json) | [Markdown](03-floor-robot.md) |
| 모브 시티 E26 | [전기자전거](04-city-bicycle.json) | [Markdown](04-city-bicycle.md) |
| 아르덴 E5 | [전기 세단](05-electric-sedan.json) | [Markdown](05-electric-sedan.md) |

Markdown 파일은 각 아이템의 **문서 가져오기**로 따로 불러올 수 있습니다. 상품명과 가격 조건은 별도 필드에서 입력합니다.
