# Demo design direction

사용자가 자리를 비운 동안 구현을 끝까지 맡겼으므로 취향 선택 라운드는 생략한다. 이 기록은 사용자 브랜드 선호를 주장하지 않는다.

실험 노트와 데이터 검사 도구의 조합을 사용한다. 밝은 회백색 배경, 검푸른 글자, 짙은 청록색 동작 버튼, 단순한 구분선과 읽기 쉬운 표를 사용한다. 화면은 패널 → 상품 비교 → 실행 → 결과의 실제 작업 순서로 구성한다. 넓은 화면에서는 고정 폭 왼쪽 탐색과 작업 영역을, 좁은 화면에서는 상단 탐색과 한 열 입력을 사용한다.

운영 UI는 시스템 글꼴을 사용한다. 브랜드 광고용 디스플레이 서체가 필요한 화면은 아니다. 출처·mock·추론 상태를 첫 화면에서 표시한다. 실험 완료 시 결과 영역의 선택 분포 막대만 짧게 전환한다. reduced-motion에서는 전환을 제거한다.

빈 목록, 불완전 입력, 서버 오류, 실행 중, 취소 요청 중, 일시 중단, 완료 상태를 모두 명시한다. 사용자 입력과 프로필은 HTML로 실행하지 않고 텍스트로 표시한다.
