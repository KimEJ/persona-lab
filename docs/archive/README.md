# 이전 구현·조사 기록

현재 구현은 [구현 기록](../IMPLEMENTATION.md), 실험 설계·사람 응답 비교는 [BIWA](https://wiki.biwa.dedyn.io/#personal-wiki/persona-lab-experiment-design)에서 관리한다.
아래 문서는 0.7까지의 구현과 이전 조사 증거다. 현재 기능·검증 결과로 읽지 않는다.
구현 사본의 본문·수치는 보존하고 문서 링크만 새 상대 경로로 조정했다. 조사 본문과 JSON 값은 수정하지 않았다. 현재 구현을 가리키는 문서 링크만 새 상대 경로로 조정했다.
